# Driving design system

The visual system is intentionally monochrome: black, white, and neutral grays only. Cards use 12-point corners and clear 2-point borders; primary controls are at least 60 points high. Typography is bold, high-contrast, and readable at dashboard distance.

Rules:

- Landscape-first composition with no desktop sidebar.
- Day, night, and high-sunlight modes.
- Left/right control placement is a first-class preference.
- Moving state removes keyboard entry, long text, dense lists, scrolling workflows, video, browsing, and settings mutation.
- Every simulated or unavailable data source is labelled.
- Motion is nonessential and minimal; state changes should not rely on animation.
- System Dynamic Type and VoiceOver labels remain enabled.
- Critical controls use both icon and text; status never relies on color.
